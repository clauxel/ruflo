# Quickstart

This quickstart is for someone discovering Ruflo from GitHub, a search result, a comparison article, or a product directory.

## 1. Open The Hosted SaaS

Start here:

- https://ruflo.online/?utm_source=github&utm_medium=documentation&utm_campaign=ruflo_docs&utm_content=quickstart_home

The first visit should answer three questions:

- Does the first screen make the agent orchestration workflow obvious?
- Is there a usable preview or concrete product surface before pricing?
- Is the Team annual path easy to find?

## 2. Learn The Workflow

1. Define a bounded goal and the repository or workspace scope.
2. Choose the agent roles, MCP tools, memory expectations, and human review checkpoints.
3. Run a small pilot before connecting sensitive repositories or long-running workflows.
4. Review the outputs, adjust prompts and permissions, then expand the workflow.

## 3. Compare Against Your Current Process

Use this simple evaluation prompt internally:

```text
Where does Ruflo reduce repeated manual work?
What private data would it touch?
Who approves the first rollout?
What evidence do we need before paying for the default plan?
```

## 4. Review Pricing

Open the tracked pricing link:

- https://ruflo.online/plans/?utm_source=github&utm_medium=documentation&utm_campaign=ruflo_docs&utm_content=quickstart_pricing

The default buyer path is Team annual. If a different plan is more appropriate, document why before checkout.

## 5. Start Checkout

Use the tracked checkout entry:

- https://ruflo.online/checkout/?utm_source=github&utm_medium=documentation&utm_campaign=ruflo_docs&utm_content=quickstart_checkout

Keep payment, onboarding, and support notes separate from this public docs project.
